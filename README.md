# Job Application Tracker

A Python and SQLite application for tracking job applications throughout the hiring process.

## Features

- Add new job applications
- Store application information in an SQLite database
- Track company name, position, application date, status, salary, and notes
- View previously saved job applications
- Organize applications by application date

## Technologies Used

- Python
- SQLite
- SQL
- Git
- GitHub

## Project Structure

- `app.py` - Main application and user interface
- `database.py` - Database creation and SQL operations
- `applications.db` - Local SQLite database generated when the program runs

## Planned Features

- Search applications by company or position
- Filter applications by status
- Update application status
- Delete applications
- Application statistics and analytics
- Web interface using HTML/CSS
- Dashboard for visualizing application progress

## Purpose

This project was created to practice software development, database management, SQL, debugging, and version control while building a practical tool for managing internship and job applications.
